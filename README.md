# Titanic-Survival-Prediction
# Titanic Data Cleaning Project

## Overview
This project focuses on cleaning and preprocessing the Titanic dataset using Python.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Tasks Performed
1. Dataset loading and statistical exploration.
2. Missing value handling using mean, median and mode imputation.
3. Categorical encoding using LabelEncoder and OneHotEncoder.
4. Age distribution visualization using Matplotlib and Seaborn.
5. Exporting the cleaned dataset into CSV format.

## Project Files
- `Titanic.ipynb` – Complete Python implementation.
- `titanic_cleaned.csv` – Processed dataset.

## Outcome
Successfully completed data cleaning, preprocessing, categorical encoding and visualization of the Titanic dataset.
